# Prompt to — сайт двух курсов

Готовый статический сайт для GitHub Pages. Ничего устанавливать и собирать не нужно.

## Состав

- `index.html` — главная с двумя направлениями.
- `game.html` — программа и тарифы Prompt to Game.
- `print.html` — программа и тарифы Prompt to Print.
- `assets/` — локальные иллюстрации, стили, значок и небольшой JavaScript.
- `.nojekyll` — служебный файл для публикации статического сайта.

## Посмотреть на компьютере

Распакуйте архив и откройте `index.html` в браузере. Не перемещайте страницы отдельно от папки `assets`. Интернет нужен только для перехода к оплате.

## Опубликовать на GitHub Pages

1. Создайте репозиторий. Для GitHub Free используйте публичный репозиторий.
2. Загрузите **содержимое этой папки в корень репозитория**: `index.html` должен лежать сразу в корне, а не в дополнительной вложенной папке. Не загружайте ZIP вместо файлов.
3. Сохраните изменения в ветку `main`.
4. Откройте Settings → Pages.
5. В Build and deployment выберите Source → Deploy from a branch.
6. Выберите ветку `main`, папку `/(root)` и нажмите Save.
7. Дождитесь завершения публикации. GitHub покажет адрес сайта в разделе Pages. Этот адрес можно использовать в анонсах.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Ссылки между страницами относительные: сайт работает и в корне домена, и по адресу проекта вида `имя.github.io/репозиторий/`.

## Что намеренно не включено

Ссылки из писем покупателям на Google Drive и закрытые чаты не размещены. Утверждение «более 70 участников» не используется, поскольку относится к дате исходного анонса. Обложки курсов заменены на предоставленные автором изображения; они показываются целиком без обрезки.

Архив не содержит паролей, ключей, платных материалов, систем сборки или привязки к другому хостингу. Для публикации нужен только этот комплект. Форма сбора данных и аналитика не подключены.
